# APA proxy

nginx config and HARICA certificate scripts for `bioeconomia.apambiente.pt`
on the APA VPS (Ploi server 125218), live since 2026-10-29. They're installed
by hand (one-off root Ploi scripts), not by `gq` or CI, so a change here
reaches the server only when someone installs it. The plan and runbooks are in
[`docs/plans/apa-harica-proxy-and-cms-move.md`](../../docs/plans/apa-harica-proxy-and-cms-move.md).
